# 窑承红脉 · 洞润古村 — 作品展示站

土古洞红色民宿群落规划设计的公开互动网页。纯静态站点：**无框架、无外部依赖、无需构建**，可以直接双击打开，也可以整体上传到任何静态托管。

---

## 一、本地查看

双击 `index.html` 即可在浏览器中打开。

如果想用本地服务器预览（更接近线上环境）：

```powershell
# 在 site 目录下执行
python -m http.server 8080
# 然后访问 http://127.0.0.1:8080
```

## 二、发布成公开网页

整个 `site` 文件夹就是一个完整网站，把**文件夹里的全部内容**上传即可。以下任选一种：

### 1. GitHub Pages（免费、最常用）

1. 新建一个 GitHub 仓库，把 `site` 里所有文件推到仓库根目录
2. 仓库 → Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main` / 目录选 `/ (root)` → Save
3. 等 1～2 分钟，地址形如 `https://你的用户名.github.io/仓库名/`

### 2. Netlify（最快，可拖拽）

打开 <https://app.netlify.com/drop>，把 `site` 文件夹直接拖进去，几秒后就会得到一个公开网址。之后可在 Site settings 里绑定自己的域名。

### 3. Vercel / Cloudflare Pages

导入仓库或上传文件夹，框架预设选 **Other / 静态站点**，构建命令留空，输出目录填 `.`（或 `site`）。

### 4. 国内云存储

阿里云 OSS、腾讯云 COS 的「静态网站托管」都可以，上传后开启静态网站模式并绑定域名即可。

> 站点总计约 **26 MB**：方案 PDF 约 10 MB、图片约 15 MB。
> 图片采用 WebP 并按用途分成「列表小图 / 灯箱大图」，列表小图随滚动按需加载，
> 首屏实际只需要约 0.4 MB，打开很快。

## 五、常见修改

**改作者署名 / 联系方式**
打开 `index.html`，搜索 `在此填写作者与联系方式`，把那一行 `<p>` 替换成你的信息即可。

**改文案**
`index.html` 里所有中文都是直接写好的明文，按版块搜索标题即可修改。

**换图**
把 `assets/img/` 里对应的 `-grid.webp` 和 `-full.webp` 换成新图（保持文件名不变）即可。

**分享到微信 / 社交平台时的封面**
`index.html` 顶部有两条 `<meta property="og:image">`，上线后建议把
`assets/img/og-cover.jpg` 改成带域名的完整地址，例如
`https://你的域名/assets/img/og-cover.jpg`。

## 六、内容来源

页面上的全部文字与图片都来自你的原始文件夹：

- 文字：从 `作品完成方案PDF/…pdf` 中提取（方案目录、色彩与材质、院落序列、功能节点、结语）
- 效果图 13 张、图纸 8 张、调研图版 5 张：从同一份 PDF 的内嵌图中还原，并按原页码标题命名
- 展板 2 幅：`作品展板/展板1.jpg`、`展板2.jpg`
- 方案册：原 PDF 原样放入 `assets/pdf/`

生成用的脚本（图片压缩、PDF 解析、页面拼装）保留在工作区的 `.build/` 目录中，
如需重新生成可以复用，但不属于网站本身，无需上传。
